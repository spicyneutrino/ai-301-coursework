# Procedure

## Read order

1. Determine the mode. Enforce scope and read voice in live mode.
2. Read the issue, thread, and repository requirements. Record requested behavior and applicable standards.
3. Read the plan and deviations before the diff. Record scope, exclusions, and expected test results.
4. Read every diff hunk and commit. Then read the title, description, and test evidence.
5. Read the rubric and evidence guide before grading.

## Evidence gathering

1. Pair each material diff operation with its plan commitment or explained deviation. Record missing planned work too.
2. Pair each test-plan expectation with its actual command, input, and observed result. Identify stand-in tests and unverified behavior.
3. Pair each repository check with its reported outcome. Record failure reasons and unavailable prerequisites.
4. Pair description claims with diff operations and test results. Record contradictions and disclosed limitations.
5. Inspect all hunks for unrelated changes and debris. Compare the description with every applicable template and disclosure requirement.

## Check execution

1. Execute every rubric row in table order, even after a failure.
2. Assign pass when its condition holds. Assign fail for contradictions or missing required evidence. Assign unclear for ambiguous evidence.
3. Cite the deciding fact or quote. Accept explicit result reports without demanding transcripts for every control. Treat frozen diffs as excerpts. Do not infer hidden helper behavior or reject outputs solely because omitted code could explain them. Re-read the relevant pair when necessary. Never invent absent evidence.
4. Distinguish an honest bounded shortfall from missing verification disguised as success. Apply each row's explicit condition.
5. Report live voice violations and procedure gaps separately. Do not create extra grading requirements.

## Verdict assembly

1. Apply the rubric verdict rule. Required unclear grades block acceptance.
2. Summarize every check. Identify the first failing required check as the main blocker when several fail.
3. Emit the fixed JSON object from SKILL.md. Include every check with its grade and evidence. Put nothing after the fence.
